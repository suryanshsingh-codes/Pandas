# 📊 About This Repository

This repository documents my journey of learning **Pandas**, one of the most powerful Python libraries for data analysis and manipulation.

It covers the fundamentals of working with **Series**, **DataFrames**, data cleaning, filtering, feature engineering, and real-world dataset analysis.

The goal of this repository is to build a strong foundation in data preprocessing and analysis for Machine Learning and AI Engineering.

# ⚙️ Getting Started

```bash
# Clone the repository
git clone https://github.com/suryanshsingh-codes/LearningPandas.git

# Navigate to the repository
cd LearningPandas

# Install dependencies
pip install pandas numpy jupyter

# Launch Jupyter Notebook
jupyter notebook
```

Open any notebook and run the cells sequentially to explore Pandas concepts and hands-on exercises.
